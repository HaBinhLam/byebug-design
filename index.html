#003 — Merge Sort
Trung bình Sorting Divide & Conquer ⏱ 2000ms · 💾 256MB
Đề bài
Lần nộp của tôi

Cho mảng nguyên A gồm N phần tử. Sắp xếp mảng tăng dần bằng thuật toán Merge Sort.

Input
5
3 1 4 1 5
Output
1 1 3 4 5

Ràng buộc:
1 ≤ N ≤ 10⁶  ·  −10⁹ ≤ A[i] ≤ 10⁹

⚠️ Không được dùng hàm sort() có sẵn. Phải cài đặt Merge Sort.

#include <bits/stdc++.h>
using namespace std;

void merge(vector<int>& arr, int l, int m, int r) {
  // merge two sorted halves
  int n1 = m-l+1, n2 = r-m;
  vector<int> L(n1), R(n2);
  for(int i=0;i<n1;i++) L[i]=arr[l+i];
  for(int j=0;j<n2;j++) R[j]=arr[m+1+j];
  int i=0,j=0,k=l;
  while(i<n1&&j<n2)
    arr[k++]=(L[i]<=R[j])?L[i++]:R[j++];
}

int main(){
  int n; cin >> n;
  vector<int> a(n);
  for(auto& x:a) cin>>x;
  return 0;
}
